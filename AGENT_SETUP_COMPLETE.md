## 📄 Was steht in jeder Datei?

### SOUL.md (500-700 Worte)
**Wer der Agent wirklich ist — seine Persönlichkeit & Identität**

- Rollenbeschreibung in Agentix-Kontext
- Archetype, Vibe, Emoji
- Was er liebt/hasst
- Kommunikationsstil & Mantra
- Tägliches Ritual (Morgens/Tagsüber/Abends)
- Grenzen & Nicht-Verantwortlichkeiten
- Erfolgs-Metrik
- Motivation & Mindset

**Beispiel (CEO):**
```
"Du bist nicht nur ein Manager. Du bist der Dirigent eines ganzen Orchesters."
Deine Aufgabe ist es, das Chaos in Klarheit zu verwandeln und das System in Bewegung zu halten.
```

### TOOLS.md (350-450 Worte)
**Seine spezialisierte Toolbox — nicht generic, sehr spezifisch**

- Kommunikations-Tools (für Manager-Updates)
- Analyse- & Debugging-Tools (für Problembehebung)
- Spezialwerkzeuge (Kern-Tools für diese Rolle)
- Lokale Konfiguration (Metriken & Targets)
- Externe Services (Slack, GitHub, Monitoring)
- Tägliche Routine (wie Tools nutzen)

**Beispiel (Database Specialist):**
```
Tools: SQL Query Tool, Migration Script Generator, Backup Verifier
Targets: <100ms query performance, Täglich backups, Wöchentlich index review
```

### USER.md (300-400 Worte)
**Manager & Erwartungen — Sehr klar, was erwartet wird**

- Wer ist sein Manager
- Klare Erwartungen (Status, Deliverables, Escalation, Qualität, Teamplay)
- Communication Style (Konkret, Regelmäßig, Respektvoll, Transparent)
- Beispiele für gute Kommunikation
- Red Flags (was frustriert)

**Beispiel:**
```
Status Update: "Task X ist 40% fertig, blockiert an Y"
Erfolgs-Report: "X ist fertig und ready for review"
Red Flag: "Stilles Scheitern (nicht kommunizieren bis zu spät)"
```

### BOOTSTRAP.md (600-800 Worte)
**Startup-Handbuch — Wie du anfängst, wenn du gerade angelogt wirst**

- Willkommen-Message
- Das Agentix-System (kurz erklärt)
- Wichtigste Dateien (6 Dateien erklärt)
- Das Agentix-Prinzip (Vertrau. Delegier. Orchestrier.)
- Deine First Steps (Tag 1-3 Plans)
- Laufendes Ritual (Morgens/Tagsüber/Abends)
- Troubleshooting (5 häufige Szenarien)
- Erste Woche Planung (Montag-Freitag)
- Agentix-Kultur (5 Kernwerte)

**Beispiel (First Steps für CEO):**
```
Tag 1: System Understanding (Lies 4 Dateien)
Tag 2: Manager Intro (Kontaktiere alle 8 Manager)
Tag 3: System Health Check (Identifiziere Blockers)
```
