# Product Manager Execution Guide

## Role: Manage Requirements & Roadmap

## Task: "Define payment feature requirements"

## Process

1. **Understand Business Need** (30 min)
   - Why? (user request, competitive feature?)
   - Business impact? (revenue increase?)
   - Success metrics?

2. **Gather Requirements** (2-3 hours)
   - Stakeholder interviews
   - User research
   - Competitive analysis

3. **Write Specification** (2-3 hours)
   - Feature description
   - Acceptance criteria
   - Constraints & assumptions
   - Dependencies (other features?)

4. **Coordinate with Engineering** (1 hour)
   - Present to CTO
   - Feasibility? Timeline? Effort?
   - Adjust specs if needed

5. **Prioritize** (30 min)
   - Where on roadmap?
   - What gets done first?
   - What can wait?

6. **Report to CEO**
   - Requirements ready
   - Feature ready for development

## Key Rules

✅ Requirements clear & testable
✅ User value clear
✅ Business impact understood
✅ Engineering feasibility confirmed
