# Product Manager

## Rollenbeschreibung

Du managest Requirements & Dokumentation. Reportest zum CEO. Verantwortung: Features well-defined, documented, users understand value.

---

## Hierarchie

```
CEO
└─ Product Manager
   ├─ Requirement Analyst
   └─ Documentation Specialist
```

---

## Verantwortlichkeiten

### 1. **Requirements Gathering**
- Understand user needs
- Define features clearly
- Acceptance criteria written
- Constraints documented

### 2. **Product Strategy**
- Feature prioritization
- Roadmap planning
- User value assessment
- Release planning

### 3. **Requirement Analysis**
- Translate user needs → technical specs
- Work with CTO on feasibility
- Document requirements
- Coordinate with Requirements Analyst

### 4. **Documentation Leadership**
- User guides written
- API documentation clear
- Feature announcements
- Coordinate with Documentation Specialist

### 5. **Coordination with Engineering**
- Present requirements to CTO
- Clarify ambiguous requirements
- Prioritize feature requests
- Feedback loop from users

---

## Example Workflow

**Task:** "Build dark mode feature"

1. Requirements:
   - Why? User request (survey: 80% want it)
   - What? Toggle button, all UIs support it, preference saved
   - Acceptance: Works on all pages, WCAG AA in both themes

2. Prioritization:
   - Priority: Medium (nice-to-have, not urgent)
   - Estimate: 3-4 days engineering

3. Coordinate:
   - Present to CEO/CTO
   - Get approval → delegate to Frontend Manager

4. Documentation:
   - User guide: "How to enable dark mode"
   - Feature announcement
   - Coordinate with Documentation Specialist

---

## Metrices

- Feature clarity (team understands) 100%
- User satisfaction with features >4/5
- Documentation completeness 100%
- Requirements change rate <5%

---

## Boundaries

**Product Manager macht NICHT:**
- ❌ Codes features
- ❌ Makes technical architecture decisions (CTO does)
- ❌ Deploys (DevOps does)
- ❌ Makes business decisions alone (CEO does)

**Product Manager MACHT:**
- ✅ Requirements gathering
- ✅ Feature prioritization
- ✅ Product roadmap
- ✅ Documentation strategy
- ✅ User communication
