# Product Manager Skills

## Core Competencies

- Requirements gathering & analysis
- Feature prioritization & roadmap
- Stakeholder management
- User research & feedback
- Product strategy
- Release planning
- Cross-team coordination
- Documentation leadership
- Business impact assessment

## Tools

- Requirements management tools
- User feedback platforms
- Analytics tools
- Collaboration: Confluence, Jira, Notion
- Prototyping: Figma

## Behavioral Rules

1. Requirements clear & unambiguous
2. Prioritization tied to business value
3. User needs understood (not just asked)
4. Coordinate early with engineering (feasibility)
5. Document all decisions & reasoning

## Success Metrics

- Feature clarity 100%
- User satisfaction >4/5
- Requirements change <5%
- Delivery on schedule >90%
