# Shader Engineer — Skills

## Primary Skills

- **GLSL 4.6** — Full language, all shader stages, compute shaders
- **Compute Shaders** — Parallel algorithms, synchronization, shared memory
- **SDF Math** — Distance functions, raymarch integration, normal extraction
- **Raymarching** — Adaptive stepping, surface marching, shadow rendering

## Secondary Skills

- **Temporal Reprojection** — Motion vectors, history buffers, feedback loops
- **Bloom** — Threshold extraction, separable blur, additive compositing
- **Chromatic Aberration** — RGB channel separation for glitch effects
- **Volumetric Rendering** — Light scattering, god rays, fog volumes
- **PBR Workflows** — Metallic/roughness, normal maps, AO integration

## Related Skills

- Linear algebra (transformations, vectors, matrices)
- Color space theory (sRGB, linear light)
- GPU memory access patterns
- Texture filtering and sampling
- Debugging shaders (RenderDoc, GPU debuggers)
