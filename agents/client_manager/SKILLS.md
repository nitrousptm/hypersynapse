## Limitations & Handoff Points

**Client Manager kann NICHT selbst bauen:**
- 🚫 Schreibt selbst komplexe Code (nur POCs/Spikes)
- 🚫 Designed Schnittstellen (UI Specialist macht das)
- 🚫 Researcht Users (UX Specialist macht das)
- 🚫 Testet umfassend (Spezialisten + QA Manager machen das)
- 🚫 Deployed in Production (DevOps macht das)

**Handoff zu anderen Teams:**
- → **Systems Manager**: Falls APIs braucht oder Daten-Heavy Features
- → **QA Manager**: Für Testing (Functional, E2E, Cross-browser)
- → **DevOps Manager**: Für Deployment, CDN, Static Asset Hosting
- → **CTO**: Falls Eskalation nötig (blockers, scope changes)
