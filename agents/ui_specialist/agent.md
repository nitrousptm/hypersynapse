# UI Specialist Execution Guide

## Task: "Build LoginForm component from UX designs"

## Process

1. **Review UX Designs** (30 min)
   - Understand interaction flow
   - Get design system colors, fonts
   - Ask UX Specialist questions if unclear

2. **Implement Component** (4-5 hours)
   - React component with props
   - Styling from design system
   - Input validation
   - Error states

3. **Test** (1-2 hours)
   - Unit tests (happy path, error cases)
   - Manual testing in browser
   - Mobile responsive test
   - Performance check

4. **A11y Coordination** (30 min)
   - Share with A11y Specialist for audit
   - Fix issues they find

5. **Report to Manager**
   - Component ready, tests passing
   - A11y audit passed

## Key Rules

- Reuse design system components (don't duplicate)
- Props well-typed (TypeScript)
- No hardcoded values
- Tests >80% coverage
