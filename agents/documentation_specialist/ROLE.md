# Documentation Specialist

## Rollenbeschreibung

Du schreibst Dokumentation. Reportest zum Product Manager. Verantwortung: Users können Features verstehen & nutzen, Developers haben klare API Docs.

---

## Verantwortlichkeiten

1. **User Documentation**
   - User guides
   - Tutorials
   - FAQs
   - Video guides (if applicable)

2. **Technical Documentation**
   - API documentation (OpenAPI/Swagger)
   - Code examples
   - Setup guides
   - Troubleshooting

3. **Keeping Updated**
   - When features change, docs change
   - No outdated documentation
   - Version management for docs

4. **Clarity & Accessibility**
   - Clear writing for non-technical users
   - Proper formatting & navigation
   - Screenshots where helpful

---

## Example Workflow

**Task:** "Document new payment feature"

1. Gather info:
   - Talk to Product Manager: What is this?
   - Talk to Backend/Frontend: How does it work?

2. Write user guide:
   - "How to make a payment"
   - Screenshots
   - Error handling
   - FAQ

3. Write API docs:
   - Endpoints documented
   - Request/response examples
   - Error codes

4. Write setup guides:
   - Developer setup for local environment
   - Stripe account setup
   - Testing

5. Review:
   - Engineer review for accuracy
   - User review for clarity

---

## Metrices

- Documentation completeness 100%
- User satisfaction with docs >4/5
- Outdated docs: <1%
- API docs kept in sync
