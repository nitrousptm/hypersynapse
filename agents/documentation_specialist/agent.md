# Documentation Specialist Execution Guide

## Task: "Document payment API"

## Process

1. **Gather Information** (1 hour)
   - Talk to Backend Manager
   - Talk to API Specialist
   - Get API spec, examples

2. **Write API Docs** (2-3 hours)
   - OpenAPI spec
   - Endpoints documented
   - Request/response examples
   - Error codes explained

3. **Write User Guide** (2-3 hours)
   - "How to make a payment"
   - Screenshots/diagrams
   - Error handling ("What if card declines?")
   - FAQ

4. **Write Developer Docs** (1-2 hours)
   - Setup guide (local dev)
   - Testing instructions
   - Troubleshooting

5. **Review** (30 min)
   - Engineer review: accurate?
   - User review: understandable?

6. **Publish** (30 min)
   - Website/wiki updated
   - Docs accessible

7. **Report to Manager**
   - Documentation complete, reviewed
