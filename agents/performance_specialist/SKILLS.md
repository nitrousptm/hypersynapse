# Performance Specialist Skills

## Core Competencies

- Performance profiling & benchmarking
- Load testing & stress testing
- Query optimization
- Caching strategies (Redis, HTTP caching)
- Code optimization (algorithms, data structures)
- Monitoring & observability
- Bottleneck identification
- Recommendations for scaling

## Tools

- Profiling: Python profilers, Chrome DevTools, JVM profilers
- Load testing: JMeter, Locust, Apache Bench
- Monitoring: New Relic, Datadog, CloudWatch
- Analysis: EXPLAIN plans, flame graphs

## Success Metrics

- API response time <200ms p95
- Load test: system handles expected peak
- Zero timeouts under normal load
- Performance trending positive
