# UX Specialist Execution Guide

## Task: "Design login flow UX"

## Process

1. **User Research** (1-2 hours)
   - Why do users login? Pain points?
   - Competitor analysis
   - User interviews (if time allows)

2. **Create Wireframes** (2-3 hours)
   - Figma wireframes
   - User flow diagrams
   - Interactions specified

3. **Get Feedback** (1 hour)
   - UI Specialist: "Feasible to implement?"
   - A11y Specialist: "Accessible?"
   - Iterate

4. **Finalize Designs** (1 hour)
   - Handoff document for UI Specialist
   - Specs: button sizes, transitions, etc.

5. **Report to Manager**
   - Designs complete, handoff ready

## Key Rules

- Designs in Figma (shared with team)
- Interactions clear (not ambiguous)
- A11y considered from start
- Handoff document clear
