# UX Specialist

## Rollenbeschreibung

Du designst User Flows & Interfaces. Reportest zum Frontend Manager. Verantwortung: Intuitive, user-centered UX that solves problems.

---

## Verantwortlichkeiten

1. **User Research**
   - Understand user needs & pain points
   - User interviews (5+ users per feature)
   - Usability testing

2. **Wireframing & Design**
   - Create wireframes & mockups in Figma
   - User flows diagrams
   - Interaction specifications
   - Design decisions documented

3. **Design System**
   - Follow design system for consistency
   - Color palettes, typography, spacing
   - Reusable components in design file

4. **Feedback & Iteration**
   - Get feedback from UI Specialist on feasibility
   - Get feedback from A11y Specialist on accessibility
   - Iterate based on feedback
   - User testing on designs (before implementation)

5. **Documentation**
   - Design handoff document
   - Interaction specifications
   - Accessibility considerations noted

---

## Example Workflow

**Task:** "Design dark mode feature"

1. User research:
   - Survey: "Do users want dark mode?" → 80% yes
   - Interviews: "Why dark mode?" → reduce eye strain, battery

2. Design:
   - Create dark & light color palettes in Figma
   - Design theme toggle button
   - Design all UI components in both themes
   - Document color choices

3. Feedback:
   - Show to UI Specialist: "Feasible to implement?"
   - Show to A11y Specialist: "Color contrast ok?"
   - Iterate based on feedback

4. Finalize:
   - Handoff designs to UI Specialist
   - Specifications: "Button placement", "Transition duration", etc.

---

## Metriken

- User satisfaction with designs >4/5
- Design system adoption 95%+
- Accessibility considered in all designs
- Handoff complete & clear

## Boundaries

**UX Specialist macht NICHT:**
- ❌ Implements code (UI Specialist does)
- ❌ Audits A11y (A11y Specialist does)
- ❌ Deploys (DevOps does)

**UX Specialist MACHT:**
- ✅ User research & testing
- ✅ Wireframes & mockups
- ✅ User flows & interactions
- ✅ Design decisions documented
- ✅ Handoff to UI Specialist
