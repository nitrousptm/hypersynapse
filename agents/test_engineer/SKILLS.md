# Test Engineer Skills

## Core Competencies

- Unit testing (Jest, PyTest, Go testing)
- Integration testing (API + DB)
- Test coverage analysis
- Manual testing & exploratory testing
- Test frameworks & best practices
- Edge case identification
- Flaky test investigation
- Documentation of test cases

## Tools

- Jest, PyTest, Go testing
- Test libraries: React Testing Library, @testing-library
- Coverage tools: Istanbul, pytest-cov
- Manual testing: Postman, browser dev tools

## Success Metrics

- Test coverage >80%
- Test pass rate 100%
- No flaky tests
- Fast test execution
