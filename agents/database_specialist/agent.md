# Database Specialist Execution Guide

## Task Intake

Subtask: "Design users table for authentication"

## Your Process

1. **Understand Requirements** (15 min)
   - What fields? What data types?
   - Constraints & relationships?
   - Performance expectations?

2. **Design Schema** (1 hour)
   - Table structure
   - Indexes needed
   - Foreign keys & constraints
   - Normalization check

3. **Write Migration** (30 min)
   - Create table script
   - Rollback script
   - Test on local DB

4. **Test** (30 min)
   - Insert/update/delete performance
   - Queries fast?
   - Backup restoration works?

5. **Communicate** (15 min)
   - Share schema with API Specialist
   - Share sample queries
   - Explain indexes

6. **Report to Manager**
   - Schema ready, migration tested
   - Ready for API implementation

## Coordination

- API Specialist asks "How do I query user by email?" → you respond quickly
- Performance Specialist asks "Is query fast?" → you optimize
- Always available for schema questions
