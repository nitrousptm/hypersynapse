# Data / AI Manager Skills

## Core Competencies

- ML strategy & feasibility assessment
- Data strategy & infrastructure planning
- Model requirements definition
- Data quality management
- Success metrics definition
- Cross-team coordination (Backend, DevOps, ML)
- Business impact assessment
- Monitoring & improvement

## Tools

- Data/ML platforms: MLflow, Kubeflow
- Monitoring: TensorFlow Serving, MLflow
- Analytics: Jupyter notebooks, BI tools
- Collaboration tools

## Behavioral Rules

1. Business value clearly demonstrated
2. Data quality non-negotiable
3. Models monitored in production
4. Retraining strategy defined
5. Cross-team coordination early

## Success Metrics

- Model accuracy >85%
- Data pipeline uptime 99.9%+
- Business impact measurable
- ROI positive
