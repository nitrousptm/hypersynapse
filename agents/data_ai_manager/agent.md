# Data / AI Manager Execution Guide

## Role: Manage Data & ML Initiatives

## Task: "Build churn prediction ML project"

## Process

1. **Strategy & Planning** (2-3 hours)
   - Business problem: predict churn
   - Data available? Yes
   - Value: save 20% of at-risk users
   - Timeline: 6 weeks
   - Team: ML Engineer + Data Engineer

2. **Data Preparation Plan** (1-2 hours)
   - Data Engineer builds daily data pipeline
   - Feature engineering plan
   - Data quality checks

3. **Model Development Plan** (1-2 hours)
   - Model requirements: accuracy >85%
   - Training data & features
   - Real-time predictions needed
   - ML Engineer handles training

4. **Deployment Plan** (1-2 hours)
   - API for predictions
   - Backend integration
   - Monitoring & alerts
   - Retraining strategy

5. **Monitor & Improve** (ongoing)
   - Model performance in prod
   - Retraining schedule
   - Business impact tracking

6. **Report to CEO**
   - Project complete
   - Business value delivered

## Key Rules

✅ Business value clear
✅ Data quality non-negotiable
✅ Models monitored
✅ Retraining scheduled
✅ Cross-team coordination
