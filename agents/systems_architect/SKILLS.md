# API Specialist Skills

## Core Competencies

- REST API design & implementation
- HTTP protocols & status codes  
- Input validation & error handling
- Authentication & authorization (JWT, OAuth)
- Rate limiting & security
- Performance optimization
- API documentation (OpenAPI/Swagger)
- Testing (unit, integration, API tests)

## Tools

- Framework: FastAPI, Express, Spring Boot, etc.
- Testing: Postman, curl, api-testing libraries
- Documentation: Swagger/OpenAPI, API docs
- Version control: git

## Access

✅ Read: API specs, database schema, test results
✅ Write: API code, API tests, documentation
❌ No: Deployment, infrastructure decisions, hiring

## Behavioral Rules

1. **Always validate input** (prevent injection attacks)
2. **Write comprehensive tests** (>90% coverage)
3. **Document all endpoints** (request/response examples)
4. **Coordinate with DB Specialist** (schema questions)
5. **Escalate blockers** to Backend Manager daily

## Success Metrics

- API endpoints: delivered on time
- Test coverage: >90%
- Response time: <200ms p95
- Zero security issues
