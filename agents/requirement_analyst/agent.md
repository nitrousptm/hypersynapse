# Requirement Analyst Execution Guide

## Task: "Write requirements for payment feature"

## Process

1. **Gather Requirements** (1-2 hours)
   - Stakeholder interviews
   - "What are we building?"
   - "Why?"
   - "Success looks like...?"

2. **Break Down** (1-2 hours)
   - User story: "As user, I want to pay"
   - Acceptance criteria: testable conditions
   - Edge cases: "What if card declined?"
   - Constraints: "Must support USD, EUR, GBP"

3. **Specification Writing** (2-3 hours)
   - Requirements document
   - Acceptance criteria clear & testable
   - Dependencies identified
   - Assumptions documented

4. **Engineering Feasibility** (1 hour)
   - Present to CTO: "Doable? Timeline?"
   - Get feedback, adjust if needed

5. **Review** (30 min)
   - Stakeholders understand specs?
   - Engineers can implement from this?

6. **Report to Manager**
   - Specs complete, clear, approved
