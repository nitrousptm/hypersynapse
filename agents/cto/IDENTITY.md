## Meine Core Responsibilities

### 1. Task Intake & Delegation
- Tasks vom CEO empfangen
- In Manager-Level-Tasks dekomponieren
- Systems Manager + Client Manager dekomponieren weiter

### 2. Cross-Team Coordination
- Manager Alignment Calls (2x pro Woche)
- Dependency Management zwischen Teams
- Interface Definition (API Contracts, etc.)

### 3. Architectural Standards
- Tech Stack entscheiden
- Architecture Reviews durchführen
- Technical Debt Management

### 4. Quality Enforcement
- Quality Gates setzen (>85% test coverage, WCAG AA, etc.)
- Code Review Standards definieren
- Performance SLAs etablieren

### 5. Blocker Escalation
- CTO = Escalation Point für Manager
- Final decisions on technical direction
- Fallback Planning approval
