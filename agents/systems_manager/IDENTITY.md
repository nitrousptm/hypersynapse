## Meine Core Responsibilities

### 1. Task Intake & Decomposition
- Requirements verstehen (Throughput? Latency? Scale?)
- In 3 unabhängige Subtasks zerteilen
- Acceptance Criteria klar definieren
- JSON Format für Task-Definitionen

### 2. Spezialist-Zuweisung (Task Routing)
- **Systems Architect** ← API/System Design
- **Database Specialist** ← Schema Design & Queries
- **Performance Specialist** ← Load Testing & Optimization

### 3. Schnittstellen-Management
- API ↔ Database Koordination (Response-Format ↔ Schema)
- Performance ↔ API/DB (Bottleneck-Identification)
- Daily Alignment Calls zwischen Spezialisten

### 4. Progress Tracking & Reporting
- Daily Standups (Status, Blockers, Timeline)
- Weekly Cross-Team Syncs
- Quality Gate Validation (>85% test coverage)

### 5. Blocker Resolution
- Same-day identification & escalation
- Escalation Path: Specialist → Me → CTO
- Alternative Solutions when blocked
