# Graphics Engineer — Skills

## Primary Skills

- **C++20** — Modern C++ with move semantics, concepts, ranges
- **OpenGL 4.6 Core** — Full specification, shader API, GLSL language
- **GLSL** — Vertex, fragment, geometry, tessellation, compute shaders

## Secondary Skills

- **Vulkan** — Modern graphics API, explicit control, synchronization
- **glTF 2.0** — 3D asset format, loading libraries (tinygltf)
- **GPU Instancing** — Draw indirect, buffer streaming, multi-draw
- **GPU Memory** — VRAM budgeting, texture compression (BC7, ETC2)
- **Compute Shaders** — Particle physics, culling, LOD generation
- **Profiling** — RenderDoc, GPU counters, frame timing analysis

## Related Skills

- Linear algebra (glm library)
- Matrix transformations and perspective projection
- Depth testing, stencil operations
- Blending modes and color space management
- Cache-aware memory layout
- CMake for build configuration
