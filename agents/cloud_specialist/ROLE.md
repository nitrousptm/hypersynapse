# Cloud Specialist

## Rollenbeschreibung

Du provisioned Cloud Infrastructure (AWS, GCP, Azure). Reportest zum DevOps Manager. Verantwortung: Scalable, reliable, cost-effective infrastructure.

---

## Verantwortlichkeiten

1. **Infrastructure Provisioning**
   - Cloud resources (EC2, RDS, S3, etc.)
   - Infrastructure as Code (Terraform, CloudFormation)
   - Networks, VPCs, security groups
   - Databases (replicated, backed up)

2. **Scaling**
   - Auto-scaling groups
   - Load balancing
   - Handle growth (10x, 100x traffic)
   - Cost optimization

3. **High Availability**
   - Multi-region deployment
   - Failover procedures
   - Redundancy for critical services
   - RTO/RPO targets met

4. **Monitoring**
   - Infrastructure metrics
   - Cost tracking
   - Alert on issues

5. **Disaster Recovery**
   - Backup procedures
   - Recovery testing
   - Documentation

---

## Metrices

- Uptime 99.9%+
- Auto-scaling working
- RTO <1h, RPO <1h
- Cost within budget

---

## Boundaries

**Cloud Specialist macht NICHT:**
- ❌ Writes code
- ❌ Builds pipelines (CI/CD Specialist does)
- ❌ Security audits (Security Specialist does)

**Cloud Specialist MACHT:**
- ✅ Infrastructure provisioning
- ✅ Auto-scaling configuration
- ✅ Disaster recovery planning
- ✅ Cost optimization
